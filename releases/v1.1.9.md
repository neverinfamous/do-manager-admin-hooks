# do-manager-admin-hooks v1.1.9

## Highlights

- **Structural Modularization**: The monolithic `index.ts` has been split into cohesive, purpose-built modules, making the library lighter and easier to maintain.
- **Enhanced Boundary Validation**: Strengthened edge-case handling across KV and SQL Durable Objects with rigorous runtime schema validation, preventing unhandled edge-case failures.
- **Adversarial Audit Completion**: Applied comprehensive fixes to ensure zero 'any' or 'as' type casting, eliminating magic strings and maximizing strict type safety.

## Changed

- **src**: Split monolithic index.ts into cohesive functional modules.
- **admin**: Enforced KV boundary validation and extracted a safer fallback response strategy.
- **hooks**: Implemented boundary validation and a unified freeze state specifically for SQL Durable Objects.
- **schemas**: Overhauled validation schemas to eliminate boundary gaps discovered during adversarial auditing.

## Security

- **deps**: Updated dependencies, security patches, and hardened GitHub Action workflows via SHA-pinning.
