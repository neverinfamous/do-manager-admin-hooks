# DO Manager Admin Hooks v1.1.16

## Highlights

- **Reliable Imports**: The package `exports` map now points to files that exist. ESM and CommonJS consumers both resolve correctly.
- **Correct Type Definitions**: Each module format now gets its matching type file, so TypeScript works under Node 16 and bundler resolution.
- **Fresh Toolchain**: Dependencies and the `tsup` build tool are current, with no known vulnerabilities.

## Changed

- **deps**: Updated `zod`, `ts-pattern`, and the dev tooling. Upgraded `tsup` to 9.0.0 and dropped an obsolete patch.
- **ci**: Refreshed GitHub Actions SHA pins. Workflows now run on a fixed `ubuntu-24.04` runner.

## Fixed

- **package**: Corrected `exports`, `main`, and `module` to match the real build output (`index.js` for ESM, `index.cjs` for CJS). Previously `import` pointed to a missing `index.mjs`.
- **package**: Added separate `index.d.ts` and `index.d.cts` type entries for ESM and CJS consumers.
