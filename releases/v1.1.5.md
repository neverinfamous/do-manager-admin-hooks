# do-manager-admin-hooks v1.1.5

## Highlights

- **Dependency Stack Modernization**: Updated core dev dependencies to latest Node 24 support targets, including TypeScript 6.0 and ESLint 10.2.
- **Security Enhancements**: Remediated Prototype Pollution, Method Injection, and Zero-step sequence process hang vulnerabilities in `flatted`, `picomatch`, and `brace-expansion` respectively via secure version pinning.

## Changed

- **Dependencies**: Bumped `@cloudflare/workers-types` from `4.20260317.1` to `4.20260405.1`.
- **Dependencies**: Bumped `eslint` from `10.0.3` to `10.2.0`.
- **Dependencies**: Bumped declared `typescript` range from `^5.7.2` to `^6.0.2` (previously resolved to `5.9.3`).
- **Dependencies**: Bumped `typescript-eslint` from `8.57.1` to `8.58.0`.
- **Build**: Handled TypeScript 6.0 internally injected deprecation rules (`ignoreDeprecations: "6.0"`) to resolve `tsup` TS5101 generation issues on `.d.ts` build paths.

## Security

- **picomatch**: Fixed Method Injection vulnerability in POSIX character classes via exact constraint override.
- **flatted**: Fixed Prototype Pollution vulnerability via exact constraint override.
- **brace-expansion**: Fixed Zero-step sequence process hang vulnerability via exact constraint override (`5.0.5`).

## Install

```bash
npm install do-manager-admin-hooks@1.1.5
```
