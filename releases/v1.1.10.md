# v1.1.10 - Hotfix: Publishing Access

This is a hotfix release to address a GitHub Actions publishing failure.

## 🛠️ Infrastructure & CI

* **Removed OIDC Provenance**: Temporarily removed the `--provenance` flag from the `pnpm publish` pipeline. This restores the ability to publish packages using legacy Granular Access automation tokens for setups where NPM's Trusted Publishing (OIDC) has not yet been configured for the GitHub repository.
