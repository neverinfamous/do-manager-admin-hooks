# v1.1.12 - Hotfix: pnpm .npmrc auth resolution

This is a hotfix release to address a GitHub Actions publishing failure where `pnpm publish` was ignoring the `NODE_AUTH_TOKEN` from the temporary user configuration file.

## 🛠️ Infrastructure & CI

* **Explicit NPM Auth Injection**: Updated `.github/workflows/publish.yml` to explicitly append `//registry.npmjs.org/:_authToken=${NODE_AUTH_TOKEN}` directly into the local project `.npmrc` file prior to publishing. This bypasses a known `pnpm` behavior where the presence of a local `.npmrc` causes it to incorrectly resolve the auth token from the global/user configuration file provided by `actions/setup-node`.
