# v1.1.14 - Hotfix: Use npm publish instead of pnpm publish

This hotfix transitions the CI pipeline from `pnpm publish` to `npm publish` to circumvent strict security constraints inside `pnpm` that interfere with GitHub Actions tokens.

## 🛠️ Infrastructure & CI

* **Publish Engine Migration**: Replaced `pnpm publish` with the native `npm publish` inside `.github/workflows/publish.yml`. `setup-node` automatically creates a highly compliant `.npmrc` for `npm publish` natively, eliminating the need for string-injection hacks, environment variable blockages, and arbitrary OIDC assumptions that `pnpm publish` forces.
