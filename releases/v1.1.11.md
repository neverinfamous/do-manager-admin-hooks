# v1.1.11 - Hotfix: OIDC Token Exchange Disablement

This is a hotfix release to address a GitHub Actions publishing failure caused by implicit OIDC token exchange detection in `pnpm publish`.

## 🛠️ Infrastructure & CI

* **Disabled Implicit OIDC**: Removed the `id-token: write` permission from the `publish.yml` workflow. In recent versions, `pnpm publish` automatically attempts an OIDC token exchange if it detects the `id-token` permission in the GitHub Actions environment, which overrides legacy token auth and results in a 404 if the package isn't configured for Trusted Publishing on NPM.
