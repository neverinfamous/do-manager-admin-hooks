# v1.1.13 - Hotfix: pnpm config set

This is a hotfix release to address a GitHub Actions publishing failure where `pnpm` rejected environment variable expansion in the local `.npmrc` file.

## 🛠️ Infrastructure & CI

* **Config Auth Approach**: Updated `.github/workflows/publish.yml` to use `pnpm config set "//registry.npmjs.org/:_authToken" "${NODE_AUTH_TOKEN}"` instead of attempting to echo the configuration into the local `.npmrc` file. This resolves the `pnpm` security restriction that blocks environment variable expansion in project-level `.npmrc` files.
